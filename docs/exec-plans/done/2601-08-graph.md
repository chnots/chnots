## 后台存储

为了优化存储，将 excalidraw 从 inlineKFile 表中迁出。统一记录到 graph_meta & graph_data 表中。

其中 graph_meta 是一个 otid 表，graph_data 是一个 sid 表。
graph_meta 中记录了版本和当前版本涉及所有的 sid，当写入时，将图数据进行如下拆分。

当前存储格式全部为 json，举例如下

- meta 部分

  ```
  {
      "foo": "<sid-foo>",
      "elements": [
          "<sid-ele1>",
          "<sid-ele2>",
          "<sid-ele3>",
      ]
  }
  ```

- data 部分
  ```
  sid-foo:  {body-foo}
  sid-ele1: {body1}
  sid-ele2: {body2}
  sid-ele3: {body3}
  ```

这样在一定程度上，可以做到节省存储空间的作用。

此处没有考虑做类似 chnot-thread 中的 order-list 的存储过程，因为

- 图笔记存储更加复杂，不一定是线性的
- 像脑图的 summary 这样的数据，多设备的数据插入在 AP 场景下会引起数据不一致。
