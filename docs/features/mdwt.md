# Mdwt 功能说明

`mdwt` 是 Markdown 正文模块，是笔记系统里最核心、最通用的文本内容形态。

## 主要是做什么的

- 保存和读取 Markdown 正文。
- 管理标签体系，支持按标签检索与补全。
- 从正文中解析待办/事件语法，并联动日程模块。
- 提供版本相关能力，支持内容历史锚点记录。

## 核心特性

- 文本优先：适配记录、文档、知识沉淀等高频场景。
- 标签驱动检索：基于 tag 与关键词组合过滤内容。
- 编辑器增强：支持补全、反链候选、粘贴转 Markdown。
- 与日程联动：在正文中写 TODO/时间信息可自动进入 Toent 链路。

## 典型使用场景

- 日常笔记、会议纪要、技术文档编写。
- 用 hashtag 构建主题索引，快速归类内容。
- 在 Markdown 里直接写待办与事件，形成“写作即计划”。

## 与其他模块的关系

- `chnot` 负责把 mdwt 内容组织成笔记目录。
- `toent` 负责承接 mdwt 解析出的 TODO/事件并生成日程实例。
