# KTab 功能说明

`ktab` 是结构化数据模块，用于在笔记系统中提供“可编辑表格”能力。

## 主要是做什么的

- 管理表格结构（列定义、列类型、表元信息）。
- 支持按单元格增量写入和按行读取。
- 支持文本、数值、日期等常见字段类型。
- 提供轻量数据库式体验，适合知识管理中的表格场景。

## 核心特性

- 动态列：列结构可扩展，不依赖固定 schema。
- 类型化存储：不同类型单元格按类型处理，兼顾灵活性和可用性。
- 在线编辑：前端可直接改单元格并即时持久化。
- 可扩展列表能力：支持排序、分页/增量加载。

## 典型使用场景

- 项目任务清单、阅读清单、数据记录表。
- 将分散信息整理成可筛选、可排序的结构化视图。
- 在笔记中创建“半结构化数据库”页面。

## 与其他模块的关系

- `chnot` 提供笔记入口和组织能力。
- `ktab` 专注表格数据本身，不处理全文检索或目录管理。
