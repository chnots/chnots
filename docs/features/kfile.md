# KFile 功能说明

`kfile` 是文件资源模块，负责上传、存储、下载、预览相关能力，是笔记系统的“附件层”。

## 主要是做什么的

- 管理文件元信息（名称、类型、大小、版本等）。
- 提供普通文件上传下载能力，支持大文件分片传输。
- 提供内联文件能力，适合保存文本片段或 data URL 这类轻量内容。
- 给其他模块提供统一的资源引用方式。

## 核心特性

- 分片上传：提高大文件上传稳定性。
- 断点续传：上传中断后可继续，减少重复传输。
- 元数据与内容分离：便于版本记录和资源管理。
- 多类型预览支持：图片、文本、通用文件可按类型展示。

## 典型使用场景

- 笔记中挂载图片、文档、压缩包等附件。
- 在图形笔记中保存内联图片内容。
- 用文本模式保存轻量资源（如 Mermaid 文本）。

## 与其他模块的关系

- `chnot` 负责把它作为一种笔记类型组织起来。
- `graph` 会使用 `kfile` 存储绘图中的图片与内联资源。
