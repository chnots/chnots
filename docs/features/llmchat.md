# LLMChat 功能说明

`llmchat` 是对话式内容模块，用于在笔记系统内管理 AI 聊天角色、模板、会话与消息记录。

## 主要是做什么的

- 管理 Bot（角色）配置，定义不同对话风格与用途。
- 管理 Prompt 模板，支持快速复用常用提问框架。
- 管理 Session（会话）生命周期，承载一次完整对话上下文。
- 管理 Record（消息）历史，支持持续追问和分支重试。

## 核心特性

- 四层数据模型：角色、模板、会话、消息分层清晰。
- 会话可持续：多轮消息可持久化，随时恢复。
- 分支能力：支持从某条消息后截断并重新生成回答。
- 使用效率优化：可按最近使用或频率快速找到常用 Bot/模板。

## 典型使用场景

- 在笔记中创建“研究会话”，持续记录问题与结论。
- 使用模板快速启动不同类型对话（总结、翻译、代码审查等）。
- 对同一问题进行多次生成，保留或替换历史分支。

## 与其他模块的关系

- `chnot` 负责把聊天会话作为一种笔记类型组织起来。
- 聊天内容可纳入统一搜索体系，支持跨类型检索。
