# Graph 功能说明

`graph` 是图形类笔记模块，负责承载“画布型内容”，包括自由绘图和思维导图两大场景。

## 主要是做什么的

- 保存与读取图形笔记内容。
- 统一支持 Excalidraw 与 MindElixir 两类编辑器数据。
- 管理 Excalidraw 图元库（library），复用常用图形素材。
- 为大体量图形内容提供可扩展的分片存储方式。

## 核心特性

- 图形内容结构化存储：元信息与实际图数据分离，便于扩展与维护。
- 双编辑器兼容：同一模块内支持白板绘图与脑图编辑。
- 自动保存友好：前端可在编辑过程进行节流/防抖提交。
- 图元库可复用：常用元素可沉淀并跨图复用。

## 典型使用场景

- 在笔记中插入白板草图、流程草图、架构草图。
- 用思维导图进行知识梳理、会议拆解、任务结构化。
- 建立个人图元库，减少重复绘图成本。

## 与其他模块的关系

- `chnot` 决定“这是一条图形笔记”，`graph` 负责其具体图内容。
- 图中图片等资源可与 `kfile` 联动完成存取。
