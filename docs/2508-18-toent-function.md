### 编辑 chnot

在编辑 `Chnot` 时定义 `TODO` 和 `TimeEvent`，如：

```
# [TODO !A] 这是一个代办
;    ID: heading-id-foo
; EVENT: 2020-12-29 12:13:14 +8:00 **3w =12t
```
